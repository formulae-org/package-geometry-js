# package-geometry-js

Geometry notation package for [Fōrmulæ](https://formulae.org) — the visual environment for **computing**, **composing**, and **conversing** with tree-structured expressions.

This repository contains the source code for the **geometry package**. It provides visualization of standard plane geometry notations.

> Part of the [formulae-org](https://github.com/formulae-org) organization: the [web application](https://github.com/formulae-org/formulae-js) plus one repository per package.

### Capabilities ###

* Geometric notation (visualization only; reduction deferred)
    * [Angle](https://en.wikipedia.org/wiki/Angle) ∠ABC
    * [Triangle](https://en.wikipedia.org/wiki/Triangle) △ABC
    * [Parallel lines](https://en.wikipedia.org/wiki/Parallel_(geometry)) AB ∥ CD
    * [Perpendicular lines](https://en.wikipedia.org/wiki/Perpendicular) AB ⊥ CD
    * [Arc](https://en.wikipedia.org/wiki/Arc_(geometry)) ⌢ over label
    * [Line segment](https://en.wikipedia.org/wiki/Line_segment) overline over label
    * [Ray](https://en.wikipedia.org/wiki/Ray_(geometry)) right arrow over label
    * [Line](https://en.wikipedia.org/wiki/Line_(geometry)) double arrow over label
